# Regression from scratch

Use `./simulation/py-sirakaya-fitting-from-scratch.ipynb`. It estimates the Cox
coefficients directly from covariates prepared from
`./simulation/felony-1989-final.xlsx`, without using Sirakaya's fitted
coefficients.

```bash
cd ./simulation
python -m jupyter lab py-sirakaya-fitting-from-scratch.ipynb
```

This optional notebook does not change the simulation model automatically.
